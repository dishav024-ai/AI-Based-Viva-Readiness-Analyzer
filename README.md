# AI-Based Viva Readiness Analyzer

An AI-powered project developed using Python to help students prepare for viva examinations.

## Features
- Viva question practice
- AI-based response evaluation
- Performance feedback
- Student-friendly interface

## Technologies Used
- Python
- Streamlit
- SQLite
- AI Concepts

## Purpose
This project helps students improve confidence and preparation for viva exams through smart evaluation and practice sessions.
